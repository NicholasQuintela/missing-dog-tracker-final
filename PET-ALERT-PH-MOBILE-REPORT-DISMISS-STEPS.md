# Pet Alert PH — Mobile Report Detail Dismiss Gestures

This frontend-only update adds mobile-friendly ways to close a missing-pet report detail view:

- Pull down firmly while the report content is already at the top.
- Press the phone/browser Back button.
- Swipe from the left edge toward the right.
- The existing X/Exit button remains available.

Normal scrolling inside a report does not close it. Desktop behavior is unchanged.

No Supabase SQL or environment-variable changes are required.
