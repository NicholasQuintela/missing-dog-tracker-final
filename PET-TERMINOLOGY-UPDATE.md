# Pet terminology update

This update changes dog-specific user-facing wording so Pet Alert PH clearly supports all kinds of pets.

## Updated text

- “Report missing dog” → “Report missing pet”
- “Report a missing dog” → “Report a missing pet”
- “Post missing dog” → “Post missing pet”
- “Dog's name” → “Pet's name”
- Dog-specific missing-report validation messages → pet wording
- Dog-specific sighting instructions, validation messages, related-report label, and placeholder → pet wording
- Dog-specific found-pet instructions and photo alt text → pet wording
- Login and account descriptions → pet wording
- Header tagline and website metadata → pet wording
- Private chat description → “pet owner”
- Example username → `pethelper.ph`

Internal identifiers such as `missing_dogs`, `dog-photos`, component names, variable names, and database fields were intentionally left unchanged to avoid breaking existing functionality.
