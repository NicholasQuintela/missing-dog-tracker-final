# Pet Alert PH Bug Report Update

This release adds a public Report a Bug form and a Bug Reports tab inside the existing administrator moderation panel.

## Supabase
Run `pet-alert-ph-bug-reports.sql` once in the Supabase SQL Editor.

## GitHub / Vercel
Upload all project files, commit, and wait for the Vercel production deployment.

## Test
1. Open Terms & Safety.
2. Select Report a Bug.
3. Complete the form and CAPTCHA.
4. Log in as an admin and open Moderation.
5. Open the Bug Reports tab and update the report status.
