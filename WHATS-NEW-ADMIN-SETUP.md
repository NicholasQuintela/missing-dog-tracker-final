# What's New admin editor

1. Open your Supabase project.
2. Go to SQL Editor and run `pet-alert-ph-whats-new-announcement.sql`.
3. Deploy the updated project.
4. Sign in with an account that has a Pet Alert PH admin role.
5. Open Admin Moderation. The **What's New announcement** editor appears below the moderation tools.
6. Edit the title and description, choose whether it is visible, then save.

Visitors see the saved announcement in the existing What's New popup. Admin access continues to use the existing `get_my_pet_alert_admin_role()` check and database RLS policy.
