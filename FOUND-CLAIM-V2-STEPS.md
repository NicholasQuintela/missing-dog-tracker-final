# Pet Alert PH – Found Claim v2

This update allows one user to submit up to 10 found claims for each missing-pet report. Only one claim may be pending at a time. After rejection, the finder can submit another claim until the 10-attempt limit is reached.

Found-claim notifications now open the proof-review screen first. The owner sees the proof image, details, Accept, Reject, and a separate Message finder button. Chat opens only when Message finder is selected.

Run `pet-alert-ph-found-claims-v2.sql` once in Supabase, then upload the project files to GitHub and wait for Vercel.
